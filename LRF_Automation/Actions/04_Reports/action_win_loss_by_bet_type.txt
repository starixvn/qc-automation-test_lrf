check total customer wl in WL by Bet Type
    [Arguments]    ${window title}    ${main frame}    ${sub frame}    ${row_number}
    [Documentation]    This action is used to check the value of total customer wl and licensee wl. we have the difference formular to calculate accroding the products. For Racing and BA products:
    ...    Total customer wl = -(Comm + Amount Due)
    ...    For the others product, the formular is:
    ...    Total customer wl = -(Licensee WL)
    ...    It will show a message if they are not equal
    Run Keyword If    '${window title}'!='None'    Select Window    ${window title}
    Run Keyword If    '${main frame}'!='None'    Select Frame    ${main frame}
    Run Keyword If    '${sub frame}'!='None'    Select Frame    xpath=//iframe[contains(@src,'${sub frame}')]
    ${total_customer_wl}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[6]/div
    ${total_licensee_wl}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[7]
    ${ba_comm}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[8]
    ${racing_revenue}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[9]
    ${amt_due_to_ba}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[10]
    ${amt_due_to_racing}    Convert and remove comma from string to number    xpath=.//*[@id='data-content']/div[${row_number}]/div[11]
    ${tmp}    Evaluate    ${total_customer_wl} + ${total_licensee_wl}+${ba_comm}+${racing_revenue}+${amt_due_to_ba}+${amt_due_to_racing}
    Run Keyword If    ${tmp}>0.01    Fail    They are not equal
    Comment    ${status}    Compare two number    ${tmp}    0
    Comment    Run Keyword If    '${status}'<>'True'    Fail    They are not equal
    Unselect Frame
