submit filters for licensee win loss
    [Arguments]    ${from date}    ${to date}    ${currency}    ${report by}    ${draw filter}    ${exclude test data}
    ...    ${product}
    [Documentation]    This action is used to submit filters for Licensee Win Loss report and Win Loss By Products report.
    ...
    ...    ${report by}= *'Daily'* or *'Monthly'*
    ...
    ...    ${draw filter}= *'Normal'* or *'No Draws'* or *'No Draws For Tunrover Only'*
    ...
    ...    ${exclude test data}= *'Yes'* or *'No'*
    ...
    ...    ${product}= *'All'* or *'Sportsbook, Racing, Number Game, Live Casino, Virtual Sports, BA, RNG Casino, Keno'*
    ...
    ...    Example:
    ...
    ...    submit filters for licensee win loss | Dec-01-2014 | Dec-07-2014 | Daily | Normal | Yes | Sportsbook, Keno
    # select date
    select date range    \    main    None    ${from date}    ${to date}
    # select currency
    Select Window
    Select Frame    main
    Select From List By Label    ${currency_listbox}    ${currency}
    # select Report By
    Run Keyword If    '${report by}'=='Daily'    Click Element    ${daily_radio_button}
    Run Keyword If    '${report by}'=='Monthly'    Click Element    ${monthly_radio_button}
    # select Draw filter
    Run Keyword If    '${draw filter}'=='Normal'    Click Element    ${normal_radio_button}
    Run Keyword If    '${draw filter}'=='No Draws'    Click Element    ${no_draws_radio_button}
    Run Keyword If    '${draw filter}'=='No Draws For Turnover Only'    Click Element    ${no_draws_for_turnover_radio_button}
    # select Exclude Test Data
    Run Keyword If    '${exclude test data}'=='Yes'    Click Element    ${yes_radio_button_exclude_data}
    Run Keyword If    '${exclude test data}'=='No'    Click Element    ${no_radio_button_exclude_data}
    Unselect Frame
    # select products
    select products filter    \    main    None    ${product}
    # click Submit button
    click element on report    \    main    None    ${submit_button}
    wait page load

    Should Be Equal    ${ac_customer_win_loss}    ${excel_customer_win_loss}

    Should Be Equal    ${ac_customer_total}    ${excel_customer_total}

check total customer wl in licensee WL
    [Arguments]    ${window title}    ${main frame}    ${sub frame}    ${row number}
    [Documentation]    This action is used to check the first row of Total Customer WL according the below formular:
    ...    Total Customer W/L = -(Licensee /WL + BA Commission + Racing Revenue + Amt Due To BA + Amt Due To Racing)
    ...    It will show a message if they are not equal
    ...
    ...    Example:
    ...
    ...    check element on report | ${window title} | main | myframe
    ...
    ...    check element on report | ${window title} | main | None
    Run Keyword If    '${window title}'!='None'    Select Window    ${window title}
    Run Keyword If    '${main frame}'!='None'    Select Frame    ${main frame}
    Run Keyword If    '${sub frame}'!='None'    Select Frame    xpath=//iframe[contains(@src,'${sub frame}')]
    ${total_customer_wl}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[27]
    ${total_licensee_wl}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[38]
    ${ba_comission}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[40]
    ${racing_revenue}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[41]
    ${amt_due_to_ba}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[43]
    Focus    xpath=.//*[@id='${row number}']/td[44]
    ${amt_due_to_racing}    Convert and remove comma from string to number    xpath=.//*[@id='${row number}']/td[44]
    ${total_tmp}    Evaluate    -(${total_licensee_wl}+${ba_comission}+${racing_revenue}+${amt_due_to_ba}+${amt_due_to_racing})
    ${status}    Compare two number    ${total_customer_wl}    ${total_tmp}
    Run Keyword If    ${status}<>True    Log    Total customer W/L is not equal with the sum as the formular
    Unselect Frame
