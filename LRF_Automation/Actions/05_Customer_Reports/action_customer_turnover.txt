submit filters for customer turnover
    [Arguments]    ${from date}    ${to date}    ${report by}    ${username}    ${product}    ${bettype}
    ...    ${minimum odds}    ${currency}    ${ticket filter}
    [Documentation]    This action is used to submit filters for Customer Turnover report.
    ...
    ...    ${report by}= *'Daily'* or *'Monthly'*
    ...
    ...    ${product}= *'All'* or *'Sportsbook, Virtual Sports, Number Game, ...'*
    ...
    ...    ${bettype}= *'All'* or *'Handicap, Odd/Even, Over/Under, ...'*
    ...
    ...    ${ticket}= *'All'* or *'Win, Loss, Draw'*
    ...
    ...    Example:
    ...
    ...    submit filters for customer turnover | \ Dec-01-2014 | Dec-03-2014 | Daily | qatest01 | All | All | 2 | CNY | All
    # select date
    select date range    \    main    None    ${from date}    ${to date}
    # select report by
    Select Window
    Select Frame    main
    Run Keyword If    '${report by}'=='Daily'    Click Element    ${daily_radio_button_customer_turnover}
    Run Keyword If    '${report by}'=='Monthly'    Click Element    ${monthly_radio_button_customer_turnover}
    # enter Username
    Run Keyword If    '${username}'!='None'    Input Text    ${username_textbox_customer_turnover}    ${username}
    # enter minium odds
    Run Keyword If    '${minimum odds}'!='None'    Input Text    ${minimum_odds_textbox_customer_turnover}    ${minimum odds}
    # select currency
    Run Keyword If    '${currency}'!='None'    Select From List By Label    ${currency_listbox}    ${currency}
    # select product
    select product checkboxes in customer turnover    ${product}
    # select bettype
    select bettype checkboxes in customer turnover    ${bettype}
    # select ticket filters
    select ticket filter    \    main    None    ${ticket filter}
    # click Submit button
    click element on report    \    main    None    ${submit_button}
    wait page load
