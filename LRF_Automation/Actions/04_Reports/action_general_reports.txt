click drilldown link in table report
    [Arguments]    ${window title}    ${main frame}    ${sub frame}    ${table}    ${row}    ${column header}
    [Documentation]    This action will try to find the drilldown link inside a table. If the link is existed, we'll click it.
    ...
    ...    Example: Find if link existed from 4th row, column 'Currency'. Then click it.
    ...
    ...    click drilldown link in table report | ${window title} | ${main frame} | ${sub frame} | ${report_table} | 4 | Currency
    Run Keyword If    '${window title}'!='None'    Select Window    ${window title}
    Run Keyword If    '${main frame}'!='None'    Select Frame    ${main frame}
    Run Keyword If    '${sub frame}'!='None'    Select Frame    xpath=//iframe[contains(@src,'${sub frame}')]
    # Find link in the columns. If existed, click on it
    ${ac_drilldown_link_status}=    Run Keyword And Return Status    Element Should Be Visible    ${table}/tbody/tr[${row}]/td[contains(@aria-describedby,'${column header}')]/a
    Run Keyword If    '${ac_drilldown_link_status}'=='True'    Click Element    ${table}/tbody/tr[${row}]/td[contains(@aria-describedby,'${column header}')]/a
    Run Keyword If    '${ac_drilldown_link_status}'!='True'    Fail    No link found in the table. Please investigate the UI.
    Unselect Frame
