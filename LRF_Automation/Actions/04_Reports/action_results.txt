submit filters for results

    # select date

    # click Submit button
    click element on report    \    main    None    ${submit_button}
    wait page load

select sport and league by index on results
    [Arguments]    ${sport index}    ${league index}
    [Documentation]    This action is used to select Sport and League in Results page based on the index of the values.
    ...
    ...    Example: select 1st Sport and 2nd League
    ...
    ...    select sport and league by index on results | 1 | 2
    Select Window
    Select Frame    main
    Run Keyword If    '${sport index}'!='None'    Select From List By Index    ${sport_listbox_results}    ${sport index}
    wait page load
    Select Window
    Select Frame    main
    Run Keyword If    '${league index}'!='None'    Select From List By Index    ${league_listbox_results}    ${league index}
    wait page load
