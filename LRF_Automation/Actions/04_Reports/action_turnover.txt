submit filters for turnover
    [Arguments]    ${year}    ${month}    ${from day}    ${to day}    ${exclude test data}    ${licensee type}
    ...    ${currency}    ${username}    ${product}
    [Documentation]    This action is used to submit filters for Turnover report.
    ...
    ...    ${exclude test data}= *'Yes'* or *'No'*
    ...
    ...    ${product}= *'All'* or *'Sportsbook, Racing, Number Game, Live Casino, Virtual Sports, BA, RNG Casino, Keno'*
    ...
    ...    Example:
    ...
    ...    submit filters for turnover | None | None | None | None | Yes | normal | Based EUR | qatest01 | Sportsbook, Racing
    Select Frame    main
    # select Exclude Test Data
    Run Keyword If    '${exclude test data}'=='Yes'    Select Checkbox    ${exclude_test_data_checkbox_turnover}
    Run Keyword If    '${exclude test data}'=='No'    Unselect Checkbox    ${exclude_test_data_checkbox_turnover}
    Run Keyword If    '${from day}'!='None' and '${to day}'!= 'None'    click element    xpath=//*[@id='MonthPickerFromDay']/a
    Run Keyword If    '${from day}'!='None' and '${to day}'!= 'None'    click element    xpath=//*[@id='TurnoverForm']/div[2]/div[2]/div/div[2]/ul/li[${from day}]/a
    Run Keyword If    '${from day}'!='None' and '${to day}'!= 'None'    Click Element    xpath=//*[@id='MonthPickerToDay']/a
    Run Keyword If    '${from day}'!='None' and '${to day}'!= 'None'    Click Element    xpath=//*[@id='TurnoverForm']/div[2]/div[3]/div/div[2]/ul/li[${to day}]/a
    # select Type - Currency
    ${ac_type_status}=    Run Keyword And Return Status    Element Should Be Visible    ${type_listbox}
    Run Keyword If    '${licensee type}'!='None' and '${ac_type_status}'=='True'    Select From List By Label    ${type_listbox}    ${licensee type}
    Run Keyword If    '${currency}'!='None'    Select From List By Label    ${currency_listbox}    ${currency}
    # enter username
    Run Keyword If    '${username}'!='None'    Input Text    ${username_textbox_turnover}    ${username}
    # select products
    select products filter    \    main    None    ${product}
    # click Submit button
    click element on report    \    main    None    ${submit_button}
    wait page load

check closing balance and opening balance

    Comment    ${row_02}    Set Variable    ${row_01} + 1

    \    ${row_02}    Evaluate    ${row_01} + 1
    \    ${locator_01}    Set Variable    xpath=.//*[@id='${row_01}']/td[15]
    \    ${locator_02}    Set Variable    xpath=.//*[@id='${row_02}']/td[3]
    \    ${number_01}    Convert and remove comma from string to number    ${locator_01}
    \    ${number_02}    Convert and remove comma from string to number    ${locator_02}
